# 🤖 AI Conversation Assistant

A conversational AI chatbot built using Python, Google Gemini, FastAPI, and Streamlit.

The chatbot supports multi-turn conversations and maintains relevant conversation context so it can remember information from earlier messages.

## 🚀 Features

- 💬 Multi-turn conversations
- 🧠 Conversation memory
- ✂️ Context-window management
- 🎯 Custom system prompt
- 🤖 Google Gemini LLM
- ⚡ FastAPI backend
- 🎨 Streamlit user interface
- 🕘 Chat history
- ⚙️ Settings and About sections
- 🛡️ API error handling
- 🔐 API key stored securely using environment variables

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google GenAI SDK
- FastAPI
- Uvicorn
- Streamlit
- Requests
- Python-dotenv
